Privacy Policy

Last updated: 3 November 2026

Gmail MCP is a personal tool used only by its developer to access the developer's own Google accounts. It is not offered to the public.

Data accessed

With the owner's consent, the app requests read-only access to Gmail messages and Google Drive files (scopes gmail.readonly and drive.readonly) of the owner's own Google accounts.

How data is used and stored

  • Data is read only when the owner asks the assistant to search or read it.
  • OAuth tokens are stored locally on the owner's computer, in a file readable only by the owner. No data or tokens are sent to any server operated by the developer.
  • Retrieved content is passed to the AI assistant the owner is using in order to answer the owner's request.
  • Data is not sold, shared with third parties, or used for advertising.

Deletion

Access can be revoked at any time at myaccount.google.com/permissions, and local tokens can be deleted by removing the token files.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
