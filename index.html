Gmail MCP

Gmail MCP is a personal, local tool that lets its owner search and read their own Gmail messages and Google Drive files, read-only, from an AI assistant (Claude) running on the owner's own computer.

It is not a public service, has no other users, and is not distributed. The source runs only on the owner's machine.

  • Access: read-only (gmail.readonly, drive.readonly)
  • Data: stays on the owner's computer
